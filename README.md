# FilmBuddy: система рекомендаций фильмов с базовыми социальными функциями

## О проекте

SPA-приложение для рекомендаций фильмов. Данный учебный проект разработан с целью углубленного изучения архитектуры веб-приложений без использования фреймворков.
Мной была полностью спроектирована и реализована клиентская часть приложения (Frontend): от дизайна и верстки до логики взаимодействия с API.

**Особенности структуры репозитория:**
Из-за особенностей сдачи группового проекта, файловая структура была объединена.
Весь исходный код находится внутри директории `zavozwww`.

* `zavozwww/services/frontend` — **Мой код (Frontend)**;
* `zavozwww/docs` — Техническая документация проекта.

## Что было реализовано
* Централизованный сервис API (`api.js`) с автоматическим внедрением JWT-токенов;
* Модульная система UI-компонентов на Vanilla JS (все модули и стили для них реализованы отдельно друг от друга);
* Система добавления в друзья и уведомления в реальном времени (реализовано через Polling в `notification.js`);
* Система аутентификации/регистрации;
* Живой поиск фильмов;
* Динамический рендеринг списков рекомендаций.

## Используемые технологии
При реализации проекта были использованы: HTML5, CSS3, Vanilla JS, FetchAPI, интеграция с REST API.

## Дальнейшие возможные варианты улучшения проекта
Внедрение адаптивной верстки для мобильных устройств.
